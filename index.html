Fonte de dados

A Bolsai não aceita chamadas de navegador — ela responde, mas sem Access-Control-Allow-Origin, e aí o navegador barra a leitura. Então quem busca é o GitHub Actions, no servidor, e publica o resultado como JSON ao lado do painel. Mesma origem: sem CORS, sem chave no aparelho, sem cota gasta aqui.

ModoAutomático lê o snapshot publicado. Ao vivo só funciona com proxy configurado abaixo.
Modo ao vivo (opcional)

Chave da API Bolsai

Todo o painel roda em api.usebolsai.com. Crie a conta com Google em usebolsai.com, gere a chave e cole aqui — ela vai no header X-API-Key e fica salva só neste aparelho. Plano grátis: 200 requisições/dia. Endpoints de dividendos, balanços e macro são do plano Pro.

Proxy (opcional)Só é necessário se o Diagnóstico acusar que a API não libera navegador. Vazio = fala direto com api.usebolsai.com.
Como enviar a chaveHeader é o documentado. Se o Diagnóstico acusar CORS no preflight, troque para parâmetro.

Cota da API

Cache e consumo

O painel guarda cada resposta por um tempo para não queimar as 200 requisições diárias do plano grátis. Cotação vale 15 min, fundamentos 12 h, dividendos e FIIs 24 h, macro 6 h, setores 7 dias.

Manutenção

Diagnóstico da API

Bate em cada endpoint usado pelo painel e mostra o status e os campos que voltaram. Use se alguma coluna aparecer vazia: os nomes de campo da Bolsai podem mudar e o painel aceita variações — o diagnóstico revela o nome real. Gasta ~8 requisições.

Dados

Backup e reset

Tudo é salvo no navegador (localStorage). Em GitHub Pages persiste entre versões; aberto como arquivo baixado pode pedir a chave de novo.

Histórico

Migração de fonte de dados

Este painel rodava em brapi.dev com a HG Brasil como reserva. Ambas saíram: tudo agora é Bolsai. O que mudou junto: o scanner faz uma chamada em vez de dezenas (screener no servidor), ROE, margem líquida e dívida/patrimônio vêm calculados em vez de aproximados por LPA÷VPA, FIIs ganharam vacância, segmento e inquilinos, e entraram as abas Ativo e Macro. Os minicontratos WIN/WDO eram exclusivos da brapi e a Bolsai não cobre derivativos — o card virou o termômetro macro, que serve à mesma decisão (comparar o yield da ordem com a renda fixa).
